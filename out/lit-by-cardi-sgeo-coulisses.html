Cette page documente le reste : ce qu’il faudrait réellement faire côté serveur, template, CDN, sitemap et hors site pour que cette page marque soit lisible, citable et fiable pour Google comme pour les moteurs de réponse IA. Les constats « aujourd’hui » ont été mesurés sur la page en production le 9 novembre 2026.

Pile observée : Next.js (pages router, rendu serveur), Cloudflare, et un CMS qui semble être CoreMedia (URL « caas »). Les propositions sont écrites pour cette pile.

1. Balises du head

Template Next.jsQui : Dev + SEOEffort : 0,5 jImpact : Élevé

Le titre de la page se limite à 12 caractères (« LIT by Cardi »), sans mot clé ni signature, et la meta description « Les marques en ligne de Sonepar » est générique, sans lien avec l’éclairage. Il n’y a ni balise robots, ni Open Graph, ni Twitter Card : un partage sur LinkedIn ou Slack n’affiche donc aucun visuel.

Pourquoi pour le SGEO. Le titre et la description sont les premiers éléments que les moteurs et les assistants IA lisent pour décider de quoi parle la page. Les directives max-snippet:-1 et max-image-preview:large autorisent des extraits complets et de grandes images dans les résultats et les aperçus IA.

3. URL et redirections

Cloudflare + Next.jsQui : DevEffort : 1 jImpact : Élevé

L’URL actuelle contient des espaces encodés et des majuscules : /brand/LIT%20by%20Cardi. Nous avons testé quatre variantes (lit-by-cardi, lit%20by%20cardi, LIT-by-Cardi, LIT+by+Cardi) : les quatre répondent 200 sans redirection, et chacune déclare sa propre URL en canonical. Par ailleurs, les liens de la page vers les catégories passent par une redirection 308 (panel-SCC060203 devient dalle-led-SCC060203) et le filtre de marque change d’écriture (LIT%20by%20Cardi devient LIT+by+Cardi).

# Cloudflare : règle de redirection (expression)
(http.request.uri.path matches "^/catalog/fr-fr/brand/.+")
  and (http.request.uri.path ne lower(http.request.uri.path)
       or http.request.uri.path contains "%20" or http.request.uri.path contains "+")
-> 301 vers concat("/catalog/fr-fr/brand/", slug(brand))   # lit-by-cardi

# Next.js : middleware.ts (équivalent applicatif)
export function middleware(req: NextRequest) {
  const m = req.nextUrl.pathname.match(/^\/catalog\/(fr-fr)\/brand\/(.+)$/i);
  if (!m) return;
  const slug = decodeURIComponent(m[2]).toLowerCase().replace(/[\s+]+/g, '-');
  if (slug !== m[2]) {
    const url = req.nextUrl.clone();
    url.pathname = `/catalog/${m[1]}/brand/${slug}`;
    return NextResponse.redirect(url, 301);
  }
}
  • Choisir /catalog/fr-fr/brand/lit-by-cardi comme URL unique, puis 301 depuis toutes les variantes.
  • Mettre à jour les liens internes, le sitemap et le canonical pour qu’ils pointent directement vers l’URL finale, sans passer par un 308.
  • Les pages catégorie filtrées par marque ont un canonical vers la catégorie sans filtre : prévoir, si l’on veut positionner « panels LIT by CARDI », des pages marque + famille indexables.

Limites et hypothèses

  • Le contenu ajouté (chiffres clés, FAQ, descriptions) reprend uniquement des faits présents sur la page Sonepar ou dans la maquette Immersive Garden. Garantie, certifications et performances chiffrées ne sont pas inventées : elles restent à fournir par CARDI et Sonepar.

  • La date « novembre 2026 » et le dateModified sont indicatifs : ils doivent suivre la vraie date de modification.
  • Le comparateur injecte les balises du head en JavaScript pour la démonstration. En production, elles sont rendues côté serveur.
